Sensing

ECG heartbeat classification using Retrieval-Augmented Generation and Large Language Models applied to real-world IoT sensor data.

About

Builds a pipeline that converts raw ECG signals into LLM-friendly text, retrieves relevant medical knowledge using hybrid BM25 + embedding search, reranks with a cross-encoder, and classifies each heartbeat as Normal or PVC with step-by-step reasoning.
